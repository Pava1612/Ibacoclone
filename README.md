# 🍦 IBACO Ice Cream Website Clone

## 📌 About the Project
This project is a front-end clone of the IBACO ice cream website, created using HTML and CSS. It showcases ice cream flavours, products, special offers, and other sections with a simple and attractive design.

## ✨ Features
- Navigation bar with menu links
- Video background on the homepage
- Ice cream flavours section
- Product cards with images and descriptions
- Special offers section
- Individual ice cream product page
- Contact form
- Google Maps integration
- Footer section

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
```text
IBACO-Ice-Cream-Clone/
```

## 🚀 How to Run the Project
1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

The objective of this project is to improve front-end development skills by creating an attractive ice cream website using HTML and CSS.
